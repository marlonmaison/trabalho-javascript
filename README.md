SENAI – ATIVIDADE PRÁTICA DE JAVASCRIPT (JS)

Nome do aluno: Marlon Mattos de Souza

Nome da atividade: Desenvolvimento de programas para cálculos de médias

Descrição dos três exercícios

Exercício 1 – Média de notas: calcula a média aritmética de quatro notas e exibe as notas e o resultado no console.

Exercício 2 – Média de vendas semanais: solicita os valores das vendas de quatro semanas, calcula a média e exibe o resultado com duas casas decimais.

Exercício 3 – Média de consumo de energia: solicita o consumo de quatro meses, calcula a média e verifica se a meta de até 150 kWh foi atingida.

Tecnologias utilizadas

JavaScript

HTML5

Visual Studio Code

Google Chrome

Git e GitHub

Orientações para executar os programas

Exercício 1: execute exemplo01.js no terminal com o comando node exemplo01.js.

Exercício 2: abra index.html com o Live Server. Informe os valores solicitados e consulte os resultados no console do navegador, acessado com F12.

Exercício 3: abra index03.html com o Live Server. Informe os consumos dos quatro meses e consulte a média e a mensagem sobre a meta no console do navegador, acessado com F12.
